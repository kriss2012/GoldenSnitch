# Definition of done
**Ticket:** AC met · tests written and executed with recorded output · review round recorded · no open P0/P1 · docs and traceability updated · status set by evidence (IMPLEMENTED ≠ TESTED).
**MVP:** see PRD §10 plus: reproducible setup (`README.md`), seeded dataset, documented API, automated tests for critical calculations, documented review process, known limitations disclosed. A polished UI with disconnected scoring, or scoring without UI, is not done.
