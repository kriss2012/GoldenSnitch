# Known limitations
Data is fully synthetic; decision/leadership/communication values are simulated or illustrative annotations, not measured behaviour. No validation against real outcomes or expert labels (no accuracy, Precision@K or agreement claim). Fit is an estimate from individual stats; no chemistry data. Weights and thresholds are unvalidated hypotheses. Pools under 8 are flagged unstable. Squad templates are simplified (3 roles per title). Percentiles shift with pool composition. No authentication/authorisation, audit log or multi-user concurrency. UI is not tested in a browser; no frontend/E2E tests. CI workflow unrun. No hosted deployment. Not built: P1 (weights UI, shortlists, notes, report export, trend screens) and all P2 items. Dependency/secret scans not run.
